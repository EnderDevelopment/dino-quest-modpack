# DinoQuest Minecraft Plugin

DinoQuest is a Minecraft plugin designed to enhance your gameplay with dinosaurs, weapons, bosses, and quality-of-life features. It includes mods for dinosaurs, weapons, bosses, mob lasso, MCA Reborn, JourneyMap, OpenBlocks elevators, iron chests, iron furnaces, backpacks, and farming realism. It also offers custom blacksmithing for creating custom weapons and tools.

## Install

1. Download the plugin JAR file from the GitHub releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server.

## Use

1. Start your Minecraft server.
2. Use the `/ciao` command to greet yourself.
